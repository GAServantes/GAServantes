### Hi, I'm Austin 👋

I build small, polished tools for the GNOME desktop on Linux: things I wanted on my own machine, made so they'd be easy for anyone to pick up.

| | |
|---|---|
| 📋 **[ClipKeep](https://github.com/GAServantes/clipkeep)** | A clipboard history that keeps formatting: bold stays bold, links stay links, images stay images. Byte-for-byte, with pins and a live preview. |
| 🌦️ **[SkyTray](https://github.com/GAServantes/skytray)** | The weather in your top bar, with hourly and 16-day forecasts and a radar you can play, including where the rain is headed. No accounts, no API keys. |
| 🖱️ **[Scroll Goblin](https://github.com/GAServantes/scroll-goblin)** | Windows-style middle-button autoscroll for Linux: hold and drag, or click, and the page scrolls faster the farther you move. Smooth on GNOME, where links and browser tabs keep their middle click. |
| 📸 **[SnapCap](https://github.com/GAServantes/snapcap)** | Screenshots and screen recording the ShareX way: click the tray icon and drag a box. Pixel magnifier, scrolling capture, colour picker, MP4 and GIF recording on the graphics card, trimming and a webcam overlay. |
| 🎬 **[Splice](https://github.com/GAServantes/splice)** | A small video editor: trim, join, add captions, change the sound, and crop on a three-lane timeline. Captions follow their clips, emoji and every script draw correctly, and saving uses your graphics card. |

All GPL-3.0 and tested on Ubuntu 24.04, most on 26.04 too. Issues and ideas welcome.
